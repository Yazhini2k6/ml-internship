# ML Internship Task 2 – Location-Based Restaurant Analysis

## 📌 Project Overview

This project was developed as part of my **Machine Learning Internship – Task 2**.

The project focuses on analyzing restaurant data based on **location, city, cuisine, pricing, ratings, and geographical coordinates**. The analysis helps identify restaurant distribution patterns, commonly available cuisines, pricing patterns, city-wise ratings, and geographical concentration of restaurants.

The project is implemented using Python and basic data analysis and visualization techniques.

---

## 🎯 Objectives

The main objectives of this project are:

- Explore and understand the restaurant dataset.
- Perform basic data preprocessing and cleaning.
- Analyze restaurants based on different cities.
- Analyze the most frequently available cuisines.
- Study restaurant distribution across different price ranges.
- Analyze geographical coordinates using latitude and longitude.
- Generate an interactive restaurant location map.
- Calculate location-based statistics.
- Extract simple descriptive insights from the dataset.
